Room To Grow

As ministries change, the website can change with them.

A church can start simple and gradually add pages over time. Navigation links can be renamed, rearranged, or removed as the site grows.

  • Add a new page for a school, outreach, or seasonal event
  • Move a link to the left or right side of the header
  • Keep the footer links in step with the main navigation
