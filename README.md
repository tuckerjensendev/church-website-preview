# Church Website Preview

This repository is a simple public preview of a free church website template.

It is meant to help pastors, church staff, and ministry teams see the kind of website they could receive without needing to look through technical code or log in to an admin area.

What this preview shows:

- A warm, mobile-friendly church website layout
- A centered logo header with navigation on both sides
- Example pages for welcome, ministries, visiting, and contact
- The kinds of updates staff can make from the admin panel, including colors, photos, wording, navigation, buttons, and pages

View the live preview:

- [Open the website preview](https://tuckerjensendev.github.io/church-website-preview/)

Notes:

- This is only a public preview site.
- The actual admin panel is not included here.
- The full working template is prepared separately for church handoff and hosting.
